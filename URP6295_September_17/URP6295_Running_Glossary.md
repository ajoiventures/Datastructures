# URP6295 Running Glossary

This glossary will be built from course files, online materials, and gap concepts.

## Seed Concepts

### Urban Data

Data used to describe cities, regions, infrastructure, land, housing, transportation, people, and public systems.

### Data Structure

The way data is organized so it can be stored, read, analyzed, and used.

### Spatial Data

Data connected to location.

### Attribute Data

Descriptive information attached to a record, feature, person, parcel, place, or geography.

### Parcel

A legally defined unit of land, often used in planning, property, taxation, and housing analysis.

### Data Dictionary

A reference that explains fields, definitions, formats, and meaning in a dataset.

## September 17 Screenshot Terms

### Function

A named set of instructions for one job. A function can receive inputs, do work, and return a result.

### Parameter

A placeholder name inside a function definition. It receives a value when the function is called.

### Argument

The actual value supplied to a function call.

### Return Value

The result a function sends back to the code that called it.

### Print

An instruction that displays a value on the screen. Printing does not make the value available as a returned result.

### List

An ordered data structure that holds multiple values.

### Accumulator

A variable that keeps a running result, such as a total while a list is being processed.

### Function Composition

Using the returned result of one function as an input to another function.

### Function Contract

The agreed rules for a function: what inputs are allowed, what result is returned, and what happens when an input is invalid.

## September 17 Data Analysis Terms

### Array

A structured collection of values, often arranged in one or more dimensions.

### Shape

The size of an array along each dimension.

### Dtype

The data type stored by a NumPy array.

### Reshape

Rearranging an array into a new shape without changing its values.

### Broadcasting

NumPy's rule for aligning compatible dimensions so one operation can apply across many combinations.

### Pairwise Distance

A distance calculated for every pair of observations.

### Norm

A calculation that turns a vector of differences into a distance or magnitude.

### Metadata

Information that describes a dataset, its fields, source, time, place, and appropriate use.

### GIS Shapefile

A common set of files used to store geographic features and their attributes.

### Spatiotemporal Data

Data that varies across both space and time.

### Mobility Flow

Movement of people, vehicles, or other entities between locations.

### Point of Interest

A mapped location with a meaningful use or destination.
